# Kemoket 2026 List

A booth listing web app for けもケット 2026, helping attendees browse booth info and plan their purchases.

Data source: https://skypalette.jp/kemoket

## Features

- Browse all booths organized by block
- Search by booth name or representative
- Favorite booths you want to visit
- Track purchase plans per booth (want to buy, quantity, amount, notes)
- Mark visited links (Web / Pixiv / Twitter)
- Dark / light theme toggle

## Development

```bash
docker compose up
```

App runs at [http://localhost:3000](http://localhost:3000) by default.
